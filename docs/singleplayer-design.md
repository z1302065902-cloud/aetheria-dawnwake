# 单人化重设计（设计契约 + 实现状态）

> 最后更新：2026-09-23（第五轮 WIP）
> 核心体验：**不是"我是 RTS 职业选手"，而是"我是一个英雄领主，带着自己的军队征服这个世界"。**
> 优先级：**英雄 > 军队 > 基地 > 经济**。玩家永远不需要当农民保姆。

## 一、设计契约（每条都要有实现 + 验证方式）

| # | 承诺 | 实现 | 验证 | 状态 |
