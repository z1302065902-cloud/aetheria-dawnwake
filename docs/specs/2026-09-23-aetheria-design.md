# Aetheria: Dawnwake — 设计稿（Phase 1）

> 2026-09-23 · 状态：Phase 1 已实现并验收（见 `docs/acceptance-phase1.md`）

## 1. Product

- **平台**：Desktop Web Browser（Chrome / Edge / Firefox / Safari），鼠标 + 键盘。
- **类型**：Single Player Fantasy RTS + Hero RPG + Roguelite。
- **玩家幻想**：你是黎明王国最后的骑士指挥官，带着一支小队和一个前哨基地，在 20 分钟内拔掉荒野氏族的营地、迎击虚空潮汐的巨兽。
- **视觉方向**：明亮、史诗、色彩饱和的幻想 3/4 俯视；轮廓清晰、单位易辨、建筑有阵营特征、技能特效夸张。
- **IP 红线**：**不复制任何已有游戏的角色/名称/地图/模型/纹理/UI/音效/音乐/技能图标/故事**。
  本项目进一步做到「零第三方素材」：所有贴图由 `SpriteFactory` 用 Canvas 程序化绘制，所有声音由 WebAudio 合成。
  世界观、阵营、英雄、单位、建筑、技能、地图、UI、音频全部原创。

## 2. Scope（Phase 1 实际交付）

| 维度 | 计划 | 交付 |
|---|---|---|
| 地图 | 3 张（Green Valley / Dark Forest / Ruined Fortress） | **1 张可玩**（Green Valley）；另 2 张生成参数就绪 |
| 战役 | 10 关 | **1 关可玩**（m01 翡翠谷地）；m02–m10 数据齐备但锁 Phase 2 |
| 英雄 | 3 名 | 3 名（数据 + 12 技能全部实现），骑士指挥官为主测英雄 |
| 单位 | 7 种 | 3 种可生产（拓荒者/剑士/弓箭手）+ 4 种数据就绪 |
| 建筑 | 8 种 | 5 种可用（城堡/兵营/射手营地/农庄/守卫塔）+ 3 种数据就绪 |
| 资源 | 3 种 | 3 种全通（金币/木材/魔法水晶） |
| 敌人 | Wildborn + Voidborn | Wildborn 6 种 + Voidborn 1 种 + 3 个 Boss 数据（1 个上场） |
| Boss | 3 个 | 1 个上场（棘齿巨兽·3 阶段），另 2 个数据就绪 |
| 音频 | 5 音乐 + 12 音效 | 3 音乐 + 24 音效（胜/负为音效而非音乐轨） |
| 存档 | 战役/英雄/装备/天赋/解锁/设置 | 战役/解锁/英雄等级/遗物/设置（装备与天赋只有字段） |

**显式不做（Phase 1 out of scope）**：多人、网络、手游适配、战争迷雾、编辑器和 mod、付费系统。
**对齐的硬性要求**：单局 15–30 分钟；同屏 20–60 单位；不出现几百单位的大场面；不出现 60 分钟长局。

## 3. 架构

| 模块 | 职责 | 文件 |
|---|---|---|
| 启动/场景 | Boot → Menu → Battle + Hud | `src/scenes/*` |
| 数据层 | 单位/建筑/英雄/技能/装备/任务/地图，全部数据驱动 | `src/data/*` |
| 世界层 | 实体（单位/英雄/建筑/资源/投射物）、地图生成、开局布点、注册表与空间查询 | `src/world/*` |
| 系统层 | 寻路、移动、命令、战斗、经济、建造、生产、AI、技能、任务、选择 | `src/systems/*` |
| 表现层 | 程序化贴图、整图地形烘焙、特效、HUD/菜单 UI、音频合成 | `src/art`, `src/fx`, `src/ui`, `src/audio` |
| 基础层 | 事件总线、空间哈希、对象池、随机、存档 | `src/core/*` |

**系统间通信**：系统只依赖 `src/systems/GameCtx.ts` 接口（world/fx/path/now/projectiles + 回调），
不直接引用 `BattleScene`；HUD 通过 `bus`（`src/core/EventBus.ts`）与 `battle.getHudState()` 单向读状态。

## 4. 硬性验收（写成可判真假的句子）

1. 一局必须能在浏览器里从主菜单跑到 Victory，**且中途不刷新页面**。
2. 放置一座建筑后，**必须**能在没有玩家干预的情况下由工人盖完（否则判定失败）。
3. 单位下令移动后**必须**真的改变坐标；任何「有路径但不移动」的状态即判定失败。
4. 英雄阵亡**不得**结束对局，必须在 30 秒后回到城堡。
5. 任何伤害都必须产生可见反馈（飘字 + 粒子）；任何一次攻击都不得静默。
6. 单局主线时长落在 **15–30 分钟**；`parTime = 20:00` 为三星基准。
7. 同屏单位数上限 **60**（玩家侧人口硬顶），加上敌人与中立总量不得超过 90（`CFG.MAX_UNITS` 预留）。
8. 模拟开销必须远低于 16.7ms/帧 的 60FPS 预算（实测 0.166ms @92 单位）。
9. 仓库内不得存在任何第三方图片/音频素材（`artifacts/` 截图除外）。
10. 存档必须能在 `localStorage` 里被读到并驱动「继续上次进度」。

## 5. 商业化（红线）

- **第一阶段完全免费**，无强制广告，**不做任何 Pay-to-Win**。
- 预留方向（未实现）：英雄/单位/基地/特效皮肤、UI 主题、战役 DLC。
- **门闸实现方式**：发布阶段用**构建期双包**（`build:demo` 免费前 N 关 / `build:full` 完整版），
  **不使用 localStorage 假门闸**（一行 `setItem` 就能破）。
- 参考 `~/.agents/skills/game-publish-workflow/SKILL.md` 与 `threejs-webgame-build-playbook` 的发布章节。
